<Warning>
`POST /quote/v3` requires a valid API key or access token on every request. Pass your key in the `x-api-key` header from your backend, or an [access token](/references/api/api_guides/access-tokens) as `Authorization: Bearer <token>` from a browser or mobile client — see [API keys and Rate Limits](/references/api/api-keys#how-to-use-an-api-key). Requests without either return `401` with `errorCode: "UNAUTHORIZED_QUOTE"`.
</Warning>
