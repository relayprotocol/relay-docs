<Warning>
  `POST /currencies/v1` is **deprecated as of October 30, 2026**: its rate limit is reduced in stages from December 14, 2026 until it is **retired on January 28, 2027**. Use [`POST /currencies/v2`](/references/api/get-currencies-v2), which returns a flat list of currencies instead of nested groups. See the [migration guide](/references/api/api_guides/migrating-to-currencies-v2#sunset-timeline) for the timeline and how to upgrade.
</Warning>
