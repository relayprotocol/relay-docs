<Warning>
  `POST /quote` is **deprecated as of November 25, 2026**: its rate limit is reduced in stages from January 9, 2027 until it is **retired on February 23, 2027**. Use [`POST /quote/v3`](/references/api/get-quote-v3), which takes the same request and returns one step per action, the same fee structure as `GET /requests/v3`, and one error shape. See the [migration guide](/references/api/api_guides/migrating-to-quote-v3#sunset-timeline) for the timeline and how to upgrade.
</Warning>
