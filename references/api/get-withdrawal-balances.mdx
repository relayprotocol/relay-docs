---
title: "Get Recovery Balances"
description: "List credited hub balances for a recovery owner"
openapi: get /withdrawals/balances
---

[How do programmatic withdrawals work?](/references/protocol/guides/withdrawals)

<Note>
Lists balances already credited to the recovery owner's account on the hub. Deposits still awaiting attestation are excluded — call [Attest Deposit](/references/api/attest-deposit) first. Discovery is eventually consistent. `ownerChainId` here is the numeric Relay chain id (as in Attest Deposit); [Request Withdrawal](/references/api/request-withdrawal) takes protocol chain slugs. These endpoints power [relay.link/withdraw](https://relay.link/withdraw) and are not yet a versioned API surface.
</Note>
